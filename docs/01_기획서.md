# 01. 기획서 — 지금 거신 번호는

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제목(가제) | 지금 거신 번호는 |
| 장르 | 세로형 텍스트 FMV 연애 어드벤처 (포토 노벨) |
| 플랫폼 | 아이폰 사파리 / 홈 화면 웹앱, 세로 전용 |
| 플레이어 | 남성 주인공 1인칭 |
| 히로인 | 3명 (전원 성인) |
| 분량 | 1회차 1~2시간, 엔딩 7개 |
| 톤 | 가볍고 달달함. 코미디는 단톡방과 주인공의 수리 실패담에서 |

**한 줄 요약**
폰이 박살 나 새 번호를 받았더니, 그 번호의 전 주인은 망원동에서 30년간 "만물수선"을 하던 할아버지였다. 쏟아지는 수리 의뢰를 얼떨결에 떠맡은 백수가 유튜브를 보며 동네를 고치러 다니다, 세 여자와 엮인다.

---

## 2. 핵심 경험

1. **폰을 들여다보는 설렘** — 알림이 오고, 입력 중 표시가 떴다 사라지고, 답장이 온다. 연애의 가장 두근거리는 순간들이 폰 화면에서 일어난다는 점을 게임으로 옮긴다.
2. **숫자 없는 호감도** — 호감은 프로필 사진, 상태 메시지, 답장 속도, 말투, 이모티콘으로만 드러난다. 플레이어는 눈치로 읽는다.
3. **고치는 사람의 이야기** — 주인공은 서툴다. 모르는 걸 아는 척할지, 솔직하게 말할지가 계속 묻는다. 무언가를 고치러 갔다가 관계가 고쳐지는 구조.

## 3. 설정

- **배경**: 서울 마포구 망원동. 골목, 망원시장, 한강공원 망원지구.
- **시기**: 봄. 3월 9일(월)부터 3월 22일(일)까지 2주.
- **주인공**: 28세 남성. 광고대행사 3년 차에 퇴사하고 2주째 쉬는 중. 거절을 못 하고 손재주는 없다. 망원동 해든빌라 201호 거주. 이름은 플레이어가 입력(기본값 "도현").
- **전 번호 주인**: 김 사장님(72세). "만물수선 김씨" 30년. 은퇴하고 제주의 딸네로 내려가며 번호를 해지했다.
- **히로인**: 카페 사장 윤서하(30), 윗집 일러스트레이터 채이안(26), 김 사장님의 손녀이자 수의사 김다온(27). 상세는 `02_캐릭터_바이블.md`.

## 4. 화면 구성 — 주인공의 폰

게임 화면 전체가 주인공의 스마트폰이다. 게임 시작은 폰 초기 설정 화면(이름 입력)이다.

| 앱 | 역할 |
|---|---|
| 잠금화면 | 게임 내 날짜·시각, 알림 카드 |
| 메신저 | 핵심. 1:1 대화방, 단톡방. 선택지는 키보드 자리의 "추천 답장"으로 표시 |
| 전화 | 음성통화·영상통화. 영상통화 = FMV 파트(세로 풀스크린 실사 컷 + 자막) |
| 사진 | CG 컬렉션. 받은 셀카, 같이 찍은 사진, 주인공이 찍은 사진 |
| 캘린더 | 날짜와 약속(수리 의뢰) 관리 |
| 메모 | 주인공의 속마음 독백, 할 일 목록, 김 사장님의 수첩(3일째 해금) |
| 설정 | 텍스트 속도, 이름 변경, 데이터 초기화 |

**대면 장면**: 약속 시간이 되면 폰 화면이 꺼지듯 어두워지고, 1인칭 풀스크린 실사 컷 + 하단 대사창으로 전환된다. 헤어지면 다시 폰 화면이 켜진다.

## 5. 폰이라서 가능한 장치

| 장치 | 설명 |
|---|---|
| 호감 신호 | 히로인의 프사·상태 메시지·답장 속도·말투가 호감 단계(1~4)에 따라 바뀐다 |
| 답장 타이밍 | "바로 답하기 / 나중에 / 읽고 넘기기"가 선택지. 늦게 답하면 게임 시간이 흐르고 상대 반응이 달라진다 |
| 동시 도착 | 두 사람에게 메시지가 동시에 오면 누구 방을 먼저 여느냐가 선택이 된다 |
| 썼다 지우기 | 어떤 선택지는 입력했다가 지우고 다른 말을 보내는 연출로 나온다. 지운 문장은 메모 앱에 남는 경우가 있다 |
| 받을까 말까 | 전화 수신 화면에서 받기/거절 자체가 선택 |
| 사진 저장 | 받은 사진을 저장할지 선택. 저장한 사진만 사진첩에 남는다 |
| 하루 결산 흐름도 | 밤에 폰을 내려놓으면 그날의 분기 흐름도가 나온다(디트로이트 비컴 휴먼식). 도달한 선택과 잠긴 선택을 보여준다 |

## 6. 핵심 루프 — 하루

게임 시간은 실시간이 아니라 **행동 기반**으로 흐른다. 하루는 네 구간이다.

1. **아침** — 알림 확인, 밤사이 온 메시지에 답장.
2. **낮** — 약속 1개(수리 의뢰 또는 만남). 의뢰가 겹치면 하나만 고를 수 있다.
3. **저녁** — 약속 1개 또는 메시지 이벤트.
4. **밤** — 할 일 1개 선택: 유튜브로 수리 공부하기(수리 실력 +1) / 누군가에게 먼저 연락하기 / 일찍 자기. 이후 영상통화 이벤트가 걸릴 수 있다. 마지막에 하루 결산 흐름도 → 자동 저장.

**수리 장면의 선택**: 의뢰마다 필요한 수리 실력이 있다. 실력이 모자라면 "아는 척 도전하기"와 "솔직하게 못 한다고 하기" 중 하나를 고른다. 이 정직함을 히로인마다 다르게 평가한다.

## 7. 전체 구조와 일정

| 일자 | 구간 | 주요 사건 |
|---|---|---|
| D1 (월) | 공통 | 새 번호 개통, 초기 설정. 수리 의뢰 폭탄. 카페 에스프레소 머신 의뢰 — 윤서하 첫 만남. 밤: "만물수선 단골방" 단톡방에 초대됨 |
| D2 (화) | 공통 | 윗집 형광등 의뢰 — 채이안 첫 만남. 저녁: 김다온의 첫 메시지 "그 번호 왜 쓰세요." |
| D3 (수) | 공통 | 동물병원 앞에서 김다온과 대면. 할아버지의 의뢰 수첩을 건네받음(메모 앱에 수첩 해금) |
| D4 (목) | 공통 | 낮 의뢰가 서하·이안에게서 동시에 옴 — 첫 양자택일. 단톡방 신경전. 밤: 첫 영상통화 |
| D5 (금) | 공통 | 한강공원 봄밤 행사에서 셋과 동시 조우. 밤: 개별 루트 결정 |
| D6~D13 | 개별 | 히로인 루트. D8 갈등이 드러남, D10 김 사장님의 전화, D11 위기, D12 고백 |
| D14 (일) | 엔딩 | 엔딩 분기 |

**루트 결정 (D5 밤)**: 호감이 가장 높은 히로인이 기준치 이상이고 핵심 플래그를 가졌으면 그 루트로 진입. 누구도 기준에 못 미치면 "혼자인 2주" 짧은 루트로 들어간다. 세부 수치는 `03_분기_지도.md`, `04_시스템_명세.md`에서 확정한다.

## 9. 시스템 개요

| 변수 | 범위 | 설명 |
|---|---|---|
| 호감 (히로인별) | 0~100 | 내부 값. 화면에는 표시하지 않음. 단계 1(0~24) 2(25~49) 3(50~74) 4(75~) |
| 수리 실력 | 0~3 | 밤에 유튜브로 공부하면 +1 |
| 플래그 | 참/거짓 | 특정 사건 경험 여부 (예: 서하에게 솔직했다, 이안의 새벽 연락에 답했다) |
| 게임 시각 | 일자 + 구간 | 행동 기반 진행 |

**저장**: 하루 결산 시 자동 저장 1개 + 도달한 날짜부터 다시 시작하는 "날짜 선택" 기능.

## 10. 톤과 문체 가이드

- 기본은 설렘과 웃음. 무거운 갈등도 한두 장면 안에 풀린다.
- 메신저 대사는 실제 카톡처럼 짧게. 한 말풍선 1~2문장, 연달아 보내는 버릇은 인물마다 다르게.
- 대면 장면 서술은 1인칭 현재형. 한 화면 2~3문장을 넘기지 않는다.
- 주인공의 속마음은 메모 앱 또는 대면 장면의 괄호 독백으로.
- 친밀한 장면은 스킨십까지 서술하고, 그 이상은 암전(`# fade`)으로 넘긴 뒤 다음 날 아침 메시지로 여운을 준다. 이미지도 손잡기, 아침 커피 두 잔 같은 암시 컷으로만 만든다.

## 12. 첫 완성본 목표

엔진 전체(M1~M5) + D1~D3의 실제 글과 그림. 세 히로인을 모두 한 번씩 만나고 하루 결산 흐름도까지 보는 데서 끝나는 판을 먼저 완성한다.
