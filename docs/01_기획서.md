## 2. 핵심 경험

1. **폰을 들여다보는 설렘** — 알림이 오고, 입력 중 표시가 떴다 사라지고, 답장이 온다. 연애의 가장 두근거리는 순간들이 폰 화면에서 일어난다는 점을 게임으로 옮긴다.
2. **숫자 없는 호감도** — 호감은 프로필 사진, 상태 메시지, 답장 속도, 말투, 이모티콘으로만 드러난다. 플레이어는 눈치로 읽는다.
3. **고치는 사람의 이야기** — 주인공은 서툴다. 모르는 걸 아는 척할지, 솔직하게 말할지가 계속 묻는다. 무언가를 고치러 갔다가 관계가 고쳐지는 구조.

## 4. 화면 구성 — 주인공의 폰

게임 화면 전체가 주인공의 스마트폰이다. 게임 시작은 폰 초기 설정 화면(이름 입력)이다.
앱은 10개다. **각 앱은 한 가지 일을 맡고, 이야기의 선택 가운데 그 앱에서만 하는 선택이 있다.** 플레이어는 "지금 어느 앱을 열어야 하는지"를 알림·배지·알약(아래)으로 안다.

| 앱 | 맡은 일 (한 줄) | 그 앱에서 하는 선택 | 쌓이는 기록 |
|---|---|---|---|
| 잠금화면 | 게임 내 날짜·시각, 밤사이 알림 | — | 앱별 알림 카드, "고를 것이 있음" 카드 |
| 메신저 | **사람과의 대화.** 1:1 방, 단골방 | 추천 답장, 썼다 지우기, 먼저 열 방 고르기, 사진 첨부 | 대화 기록, 안 읽음 |
| 전화 | **목소리.** 음성·영상통화(FMV), 연락처, 음성사서함 | 받을까 말까, 연락처에서 누구에게 전화·문자할지 | 최근 기록(받은/건/거절/부재중), 연락처 메모, 음성 메시지 |
| 튜브 | **배우는 곳.** 수리 영상 (오반장 수리교실) | 밤에 볼 영상 고르기 → 수리 장면의 선택지가 바뀐다 | 보관함, 영상별 "핵심 정리" |
| 지도 | **가는 곳.** 망원동 지도와 약속 장소 | 낮에 어디부터 갈지 (겹친 의뢰 중 하나) | 다녀온 곳과 시각, 새로 알게 된 장소 핀 |
| 사진 | **남기는 것.** CG 컬렉션 | 받은 사진 저장 여부 (나중에 대본이 확인한다) | 받은 사진 / 내가 찍은 사진 앨범 |
| 캘린더 | **약속과 날씨.** 의뢰·만남 일정 | — (겹친 약속, 취소된 약속이 보인다) | 약속, 행사, 날씨 |
| 메모 | **속마음과 할 일.** 독백, 할 일, 김 사장님의 수첩(D3 해금) | 수첩을 미리 읽었는지가 수리 장면에 반영된다 | 메모, 할 일, 보내지 못한 말, 수첩 |
| 스냅 | **남들이 보는 얼굴.** 세 히로인과 두부의 SNS | 좋아요, 댓글 (히로인이 알아챈다) | 게시물, 댓글 |
| 망원살이 | **동네가 보는 것.** 동네 게시판 | 동네 글에 답글 (도움 요청, 나눔) | 동네 소식, 내 답글 |
| 설정 | 텍스트 속도, 이름, 날짜 선택, 엔딩 기록, 휴대폰 정보 | 혼자인 2주의 마지막 선택(번호 넘기기) | 본 엔딩 목록 |

- **알약 (진행 알림)**: 이야기가 다른 앱에서 선택을 기다리면, 홈 화면 위와 다른 앱의 헤더 아래에 "튜브 · 오늘 밤 볼 영상"처럼 알약이 뜬다. 누르면 그 앱(대화방)이 열린다.
- **배지**: 새 소식이 있는 앱 아이콘에 숫자, 고를 것이 있는 앱에는 점.

**대면 장면**: 약속 시간이 되면 폰 화면이 꺼지듯 어두워지고, 1인칭 풀스크린 실사 컷 + 하단 대사창으로 전환된다. 헤어지면 다시 폰 화면이 켜진다.
**영상 재생**: 튜브에서 영상을 고르면 영상 플레이어 화면이 되고, 오반장의 설명이 자막으로 나온다. 다 보면 핵심 정리가 보관함과 메모에 남는다.

| 장치 | 설명 |
|---|---|
| 호감 신호 | 히로인의 프사·상태 메시지·답장 속도·말투가 호감 단계(1~4)에 따라 바뀐다 |
| 답장 타이밍 | "바로 답하기 / 나중에 / 읽고 넘기기"가 선택지. 늦게 답하면 게임 시간이 흐르고 상대 반응이 달라진다 |
| 동시 도착 | 두 사람에게 메시지가 동시에 오면 누구 방을 먼저 여느냐가 선택이 된다 |
| 썼다 지우기 | 어떤 선택지는 입력했다가 지우고 다른 말을 보내는 연출로 나온다. 지운 문장은 메모 앱에 남는 경우가 있다 |
| 받을까 말까 | 전화 수신 화면에서 받기/거절 자체가 선택 |
| 사진 저장 | 받은 사진을 저장할지 선택. 저장한 사진만 사진첩에 남고, 히로인이 나중에 알아챈다 |
| 배운 만큼 고친다 | 튜브에서 본 영상과 미리 읽은 수첩 쪽이 수리 장면의 선택지를 바꾼다 (아는 척 대신 "배운 대로 하기") |
| 모르는 번호 | 김 사장님을 찾는 전화가 모르는 번호로 걸려 온다. 받기 전에는 누구인지 모른다 |
| 음성사서함 | 거절하거나 못 받은 전화는 음성 메시지로 남는다. 그 안에만 있는 대사가 있다 |
| 하루 결산 흐름도 | 밤에 폰을 내려놓으면 그날의 분기 흐름도가 나온다(디트로이트 비컴 휴먼식). 도달한 선택과 잠긴 선택을 보여준다 |

## 6. 핵심 루프 — 하루

게임 시간은 실시간이 아니라 **행동 기반**으로 흐른다. 하루는 네 구간이다.

1. **아침** — 알림 확인, 밤사이 온 메시지에 답장. 망원살이·스냅에 동네 소식.
2. **낮** — 약속 1개(수리 의뢰 또는 만남). 의뢰가 겹치면 **지도**에서 어디부터 갈지 고른다 (나머지는 캘린더에서 취소된다).
3. **저녁** — 약속 1개 또는 메시지·전화 이벤트.
4. **밤** — 할 일 1개 선택: 튜브로 수리 공부하기(튜브에서 영상 고르기) / **전화 앱에서** 누군가에게 먼저 연락하기 / 일찍 자기. 이후 영상통화 이벤트가 걸릴 수 있다. 마지막에 하루 결산 흐름도 → 자동 저장.

**수리 장면의 선택**: 의뢰마다 필요한 지식이 있다. 그 영상을 봤거나 수첩의 그 쪽을 읽었으면 "배운 대로 하기"가 나온다. 모르면 "아는 척 도전하기"와 "솔직하게 못 한다고 하기" 중 하나를 고른다. 이 정직함을 히로인마다 다르게 평가한다.

## 9. 시스템 개요

| 변수 | 범위 | 설명 |
|---|---|---|
| 호감 (히로인별) | 0~100 | 내부 값. 화면에는 표시하지 않음. 단계 1(0~24) 2(25~49) 3(50~74) 4(75~) |
| 수리 실력 | 0~3 | 튜브 영상을 볼 때마다 +1 |
| 수리 지식 | 참/거짓 | 영상마다 하나 (`k_boiler` 등). 그 수리 장면에서 "배운 대로 하기"가 열린다 |
| 플래그 | 참/거짓 | 특정 사건 경험 여부 (예: 서하에게 솔직했다, 이안의 새벽 연락에 답했다) |
| 게임 시각 | 일자 + 시각 | 행동 기반 진행 |
| 기록 | — | 사진 저장, 수첩 읽음, 다녀온 곳, 본 영상, 좋아요·댓글 — 대본이 나중에 확인한다 |

**저장**: 대사 한 줄마다 이어하기 자동 저장 + 날짜별 시작 지점("날짜 선택"). 자세한 것은 `04_시스템_명세.md`.

## 10. 톤과 문체 가이드

- 기본은 설렘과 웃음. 무거운 갈등도 한두 장면 안에 풀린다.
- 메신저 대사는 실제 카톡처럼 짧게. 한 말풍선 1~2문장, 연달아 보내는 버릇은 인물마다 다르게.
- 대면 장면 서술은 1인칭 현재형. 한 화면 2~3문장을 넘기지 않는다.
- 주인공의 속마음은 메모 앱 또는 대면 장면의 괄호 독백으로.
- 친밀한 장면은 스킨십까지 서술하고, 그 이상은 암전(`# fade`)으로 넘긴 뒤 다음 날 아침 메시지로 여운을 준다. 이미지도 손잡기, 아침 커피 두 잔 같은 암시 컷으로만 만든다.
