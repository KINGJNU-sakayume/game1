# 04. 시스템 명세 (초안)

> 상태: **초안** — M3 구현과 함께 작성. 수치는 플레이 테스트 후 조정한다.
> 루트 진입 기준치와 엔딩 조건은 `03_분기_지도.md`에서 확정한다.

## 1. 변수

모든 게임 변수는 ink 변수로 둔다. 정의 파일: `story/system.ink`. 엔진(`src/engine/director.ts`)은 대사 한 줄과 선택 한 번이 끝날 때마다 이 변수를 읽어 화면에 반영한다.

| ink 변수 | 범위 | 기본값 | 설명 |
|---|---|---|---|
| `player_name` | 문자열 | "도현" | 주인공 이름. 설정 앱에서 바꾸면 엔진이 덮어쓴다 |
| `aff_seoha` · `aff_ian` · `aff_daon` | 0~100 | 0 | 히로인별 호감. **화면에 숫자로 보이지 않는다** |
| `skill` | 0~3 | 0 | 수리 실력 |
| 플래그 (자유) | true/false | false | `VAR f_seoha_honest = false`처럼 `f_`로 시작. 엔진은 읽지 않는다 |

### 대본에서 바꾸는 법

```ink
~ raise(aff_seoha, 5)     // 호감 +5 (0~100을 넘지 않음)
~ raise(aff_ian, -3)      // 호감 -3
~ study()                 // 수리 실력 +1 (최대 3)
~ f_seoha_honest = true   // 플래그
{aff_daon >= 50: 밥은.|그 번호 왜 쓰세요.}   // 조건에 따라 다른 대사
```

## 2. 호감 단계

| 단계 | 호감 | |
|---|---|---|
| 1 | 0~24 | 첫 만남 |
| 2 | 25~49 | 호의 |
| 3 | 50~74 | 관심 |
| 4 | 75~ | 설렘 |

### 호감 변화량 가이드 (초안)

| 행동 | 변화 |
|---|---|
| 작은 호의 (정중한 답장, 약속 지키기) | +3 ~ +5 |
| 그 인물이 **가장 중요하게 보는 행동** (서하: 솔직함 / 이안: 새벽 연락에 답하기, 구체적인 감상 / 다온: 정직함, 시간 약속) | +8 ~ +15 |
| 싫어하는 행동 (허세, 대충 칭찬, 지각 등) | −5 ~ −10 |

D5 밤 루트 결정까지 한 히로인에게 집중하면 3단계(50) 안팎에 닿도록 선택지를 배치한다.

## 3. 호감 신호 (숫자 대신 보이는 것)

단계가 바뀌면 다음 메시지부터 바로 반영된다. 값은 `02_캐릭터_바이블.md`에서 가져왔고 `src/story/cast.ts`의 `STAGE_SIGNALS` · `READ_DELAY`에 있다.

| 신호 | 어디에 보이나 |
|---|---|
| 프로필 사진 | 대화 목록, 말풍선 옆 아바타, 프로필 보기(아바타를 누르면 열림) |
| 상태 메시지 | 1:1 대화방 헤더의 이름 아래, 프로필 보기 |
| 답장 속도 | 주인공 메시지 옆의 **"1"(안 읽음)** 이 사라질 때까지 걸리는 시간 |
| 말투 | 대본 담당 — `{aff_seoha >= 25: …|…}` 조건문으로 단계별 대사를 쓴다 |

### 읽음 시간 (초, 텍스트 속도 설정이 곱해짐)

| | 1단계 | 2단계 | 3단계 | 4단계 |
|---|---|---|---|---|
| 서하 | 5 | 3.5 | 2 | 1 |
| 이안 | 1.2 | 0.8 | 0.5 | 0.3 |
| 다온 | 7 | 5 | 3 | 1.5 |
| 그 외 | 1.5 | | | |

- 1:1 방에서 주인공이 메시지를 보낸 뒤 **상대의 다음 대사**가 나오기 전에 이 시간만큼 기다리고 "1"을 지운다. 그다음 입력 중 표시가 나온다.
- 그 대사에 `# wait:`가 있으면 그 시간을 읽는 시간으로 쓴다 (예: 이안 마감 주간엔 `# wait: 20`).
- 단톡방에는 읽음 표시가 없다.

## 4. 게임 시각

- 날짜: `# day: N` (D1 = 3월 9일 월요일 … D14 = 3월 22일 일요일)
- 시각: `# time: HH:MM` — 실시간이 아니라 대본이 정한다. 메시지 시각, 잠금화면 시계, 홈 위젯에 쓰인다.
- 하루 네 구간(아침·낮·저녁·밤)은 시각으로 표현한다. 구간별 규칙은 `03_분기_지도.md`에서 정한다.

## 5. 저장

플레이어가 직접 저장하지 않는다. 모두 자동이다. localStorage `jgbn_` 접두사.

| 키 | 언제 | 내용 |
|---|---|---|
| `jgbn_resume` | **선택지가 나올 때마다**, 날짜가 바뀔 때 | 이어하기 지점 1개. 앱을 다시 열면 여기서 이어진다 |
| `jgbn_days` | 날짜가 바뀔 때(`# day:` 줄을 처리한 직후) | 날짜별 시작 지점. 설정 앱 **날짜 선택**에 쓴다 |
| `jgbn_log` | resume과 함께 | 메시지 기록. 저장본마다 메시지 개수만 기억해 앞부분을 공유한다 |

- 각 저장본: ink 진행 상태(`story.state.ToJson()`), 게임 시각, 안 읽음 수, 현재 방, 메시지 개수.
- 기획서는 "하루 결산 시 자동 저장 1개"였지만, 폰 게임 특성상 앱을 닫는 일이 잦아 **선택지마다 이어하기 저장**을 추가했다. 하루 결산(M5) 직후는 다음 날 시작 지점이 되므로 기획 의도와 같다.
- **날짜 선택**: 고른 날짜 시작 지점을 이어하기로 만들고, 그 뒤 날짜 저장본은 지운다(다른 갈래가 되므로).
- **데이터 초기화**: `jgbn_`로 시작하는 키를 모두 지운다.
- 대본이 크게 바뀌어 저장본을 불러오지 못하면 처음부터 시작한다(개발 중 주의).
