# 10. 이미지 프롬프트 — 남은 그림 전부

> `07_아트_파이프라인.md`의 **원래 프롬프트 체계**(기준 이미지 → 표정 → 장면, 5장의 공통 블록, 6장의 표정 템플릿, 7장의 손 틀, 8장의 배경)를 그대로 따른다. 이미 만든 D1~D2 이미지와 같은 방식이라 톤이 이어진다.
> 대본이 부르는 이미지 중 아직 없는 **86장** + 먼저 만들어야 하는 기준 그림 **2장** = **88장**. 코드 블록 하나가 ChatGPT에 붙여 넣을 프롬프트 하나다(공통 블록이 이미 붙어 있다).

## 0. 쓰는 법

1. 항목의 **첨부**에 적힌 이미지를 먼저 첨부한다. 파일은 저장소 `raw/` 폴더의 원본(PNG)이다. 첨부가 여러 개면 한 메시지에 모두 첨부한다.
2. 코드 블록을 그대로 붙여 넣는다. 인물은 한 장씩 만들고, 얼굴이 기준 이미지와 다르면 다시 만든다.
3. 결과를 **항목 제목의 파일명 그대로** 저장해 `raw/`에 올린다(PNG·JPG 그대로 — WebP 변환과 폴더 정리는 빌드가 한다).
4. **순서대로** 만든다. 뒤의 항목이 앞에서 만든 이미지를 첨부한다(예: 다온 컷은 1장의 `daon_ref_01`, 같은 장소의 밤 배경은 낮 배경).
5. 비율: 세로 9:16. ChatGPT가 세로 2:3으로 만들어도 된다 — 게임 화면이 가운데를 잘라 쓰므로 중요한 것은 가운데에 둔다. 예외: `tube_cg_jeju_hands_01`만 가로.
6. 화면에서 잘리는 모양: 대화방 사진 9:16 · 스냅 게시물 4:5 · 사진첩 썸네일 정사각형 · 대면 장면 전체 화면 · 튜브 영상 16:9.
7. 한 번에 여러 장: ChatGPT 화면에서는 한 메시지에 한 장씩이 가장 안전하다. 같은 인물은 한 대화창에서 이어 만들되, **매번 기준 이미지를 다시 첨부**한다.
