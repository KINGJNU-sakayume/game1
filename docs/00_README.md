# 지금 거신 번호는 — 프로젝트 문서

세로형 텍스트 FMV(Full Motion Video) 연애 게임. 아이폰 사파리와 홈 화면 웹앱(PWA, Progressive Web App)에서 플레이한다.
화면 전체가 "주인공의 스마트폰"이고, 메신저·전화·튜브·지도·사진·캘린더·메모·스냅·망원살이·설정, 10개의 앱을 통해 이야기가 진행된다.
14일(3월 9일~22일), 세 히로인 루트와 혼자인 2주, 엔딩 7개. 1회차 1~1.5시간.

---

## 이 문서를 읽는 AI에게 — 작업 규칙

1. 코드를 쓰기 전에 이 README와 이번 작업에 해당하는 문서를 먼저 읽는다.
2. 한 번에 한 마일스톤만 작업한다. 요청받지 않은 기능을 미리 만들지 않는다.
3. `docs/`와 `story/` 안의 파일은 요청 없이 수정하지 않는다. 스토리 내용은 사람이 정한다(요청이 있을 때만 AI가 초고를 쓴다).
4. 모바일 세로 화면(390×844, 아이폰 기준)이 최우선이다. 데스크톱은 가운데 정렬된 폰 프레임으로 보이기만 하면 된다.
5. 이미지 에셋이 없어도 앱이 깨지지 않게 플레이스홀더로 동작해야 한다.
6. 의존성을 추가할 때는 이유를 한 줄로 남긴다.
7. 작업이 끝나면 해당 마일스톤의 완료 기준 체크리스트 결과와 변경한 파일 목록을 보고한다.
8. 대본(`story/`)이나 대본이 쓰는 id(`src/story/`)를 고치면 `npm run playtest`를 돌려 **태그 경고 0개, 엔딩 7개 모두 도달, 막다른 길 없음**을 확인한다.

## 폴더 구조

```
/
├─ docs/                  이 문서들
├─ story/                 ink 대본
│  ├─ main.ink            진입점 (INCLUDE 목록)
│  ├─ system.ink          변수·도우미 함수 (엔진이 읽음)
│  ├─ d01.ink ~ d05.ink   공통 구간
│  ├─ route_seoha.ink · route_ian.ink · route_daon.ink · route_alone.ink
│  ├─ endings.ink         엔딩 7개
│  ├─ videos.ink          튜브 영상 (터널)
│  └─ boss.ink            김 사장님 전화 (루트마다 불러 쓰는 조각)
├─ raw/                   원본 이미지 (빌드할 때 WebP로 바뀌어 public/assets로)
├─ public/assets/         characters · cg · backgrounds · ui
├─ scripts/
│  ├─ vitePluginInk.ts    빌드할 때 ink 컴파일
│  ├─ convert-images.mjs  raw → WebP
│  └─ playtest.ts         대본 점검: 수백 번 끝까지 플레이 (npm run playtest)
├─ src/
│  ├─ engine/             대본 실행(director), 상태(store), 저장(save)
│  ├─ apps/               앱 10개 (ids.ts · registry.ts에 목록)
│  ├─ phone/              잠금·홈·앱 껍데기·무대·알림·알약·하루 결산·엔딩 카드
│  └─ story/              대본이 쓰는 id: 인물(cast)·장소(places)·영상(videos)·스냅 계정(social)·날씨·엔딩
└─ .github/workflows/
   └─ deploy.yml          GitHub Pages 자동 배포
```

## 기술 요약

- 화면: Vite + React + TypeScript
- 이야기: ink 스크립트 언어 + inkjs 런타임 (M2부터)
- 배포: `main` 브랜치 push → GitHub Actions → GitHub Pages
- 앱화: PWA (홈 화면에 추가하면 주소창 없는 전체화면)
- 저장: 브라우저 localStorage (자동 저장, 세이브 버전 2)
- 대본 점검: `npm run playtest` (Node 22.6 이상. 무작위·히로인 집중 플레이 결과, 태그 경고, 지나가지 않은 knot)
