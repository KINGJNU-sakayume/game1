# 이번 작업: M1 — 폰 껍데기 + 자동 배포

목표: 아이폰 사파리에서 "주인공의 스마트폰"처럼 보이고 동작하는 빈 껍데기를 만들고, main 브랜치에 push하면 GitHub Pages로 자동 배포되게 한다.
이번 단계에서는 스토리, 메신저 대화, ink 연동을 만들지 않는다. 모든 앱 내부는 빈 화면이어도 된다.

## 기술 스택
- Vite + React + TypeScript
- 스타일: 일반 CSS + CSS 변수 (Tailwind, CSS-in-JS 사용 금지)
- 라우팅 라이브러리 사용 금지. 화면 전환은 React 상태로 관리
- 아이콘: lucide-react 허용
- PWA: vite-plugin-pwa
- 폰트: Pretendard (jsDelivr CDN), 실패 시 시스템 폰트로 대체

## 화면 흐름
초기 설정(첫 실행만) → 잠금화면 → 홈 화면 → 각 앱 → 홈 화면

1. 초기 설정 화면
   - 새 폰을 켰을 때의 설정 화면 느낌. "안녕하세요" → 이름 입력(기본값 "도현") → "설정 완료"
   - 이름은 localStorage 키 `jgbn_profile`에 JSON으로 저장. 모든 저장소 접근은 try/catch로 감싼다
   - 저장된 이름이 있으면 이 화면을 건너뛴다

2. 잠금화면
   - 큰 시계와 날짜: 게임 내 시각 (M1은 고정값 "3월 9일 월요일", "08:12")
   - 알림 카드 1개 (더미): "만물수선 단골방 · 새 메시지 3개"
   - 위로 스와이프하거나 화면을 탭하면 홈 화면으로

3. 홈 화면
   - 상단에 게임 시각 위젯 (날짜 + 시각)
   - 앱 아이콘 6개 격자: 메신저, 전화, 사진, 캘린더, 메모, 설정
   - 메신저 아이콘에 빨간 숫자 배지 (더미 3)
   - 배경화면: CSS 그라데이션 임시 (나중에 bg_wallpaper_01.webp로 교체 예정이므로 경로를 상수로 분리)

4. 앱 화면 (공통 껍데기)
   - 상단 헤더: 뒤로 버튼 + 앱 이름
   - 본문: "준비 중" 빈 화면
   - 설정 앱만 실제 기능:
     - 텍스트 속도: 느림 / 보통 / 빠름 (저장만)
     - 이름 변경
     - 데이터 초기화: 확인 모달 → localStorage의 `jgbn_` 접두사 키 전부 삭제 → 초기 설정 화면으로

5. 전환 애니메이션
   - 앱 열기: 탭한 아이콘 위치에서 확대되며 열림 (scale + opacity, 200~250ms)
   - 앱 닫기: 뒤로 버튼, 또는 화면 하단 홈 인디케이터 바를 위로 스와이프 → 홈으로 축소
   - prefers-reduced-motion이면 페이드만

## 레이아웃 규칙 (중요)
- 기준 뷰포트 390×844. 게임 루트는 height: 100dvh. 스크롤은 앱 본문 안에서만 허용
- body 스크롤과 당겨서 튕기기 금지: overscroll-behavior: none, 루트 overflow hidden
- viewport 메타: width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no
- 노치와 홈 인디케이터를 피한다: 상단·하단 여백에 env(safe-area-inset-top/bottom) 적용
- 실제 기기의 상태바와 게임 UI가 겹치지 않게 한다. 게임 내 시각은 상태바를 흉내 내지 말고 잠금화면 시계와 홈 화면 위젯으로만 보여준다. 기기 상단 safe-area 영역은 비워 둔다
- 가로 방향일 때는 "세로로 돌려주세요" 오버레이를 띄운다
- 데스크톱처럼 넓은 화면(가로 500px 초과)에서는 가운데에 390×844 폰 프레임(둥근 모서리, 그림자) 안에 게임을 표시한다
- 터치 대상은 최소 44×44px. touch-action: manipulation으로 더블탭 확대 방지
- 입력창을 제외하고 텍스트 선택과 길게 누르기 메뉴 비활성화 (-webkit-user-select: none, -webkit-touch-callout: none)
- 라이트/다크는 시스템 설정(prefers-color-scheme)을 따른다. 색은 styles/tokens.css의 CSS 변수로만 정의

## PWA / iOS
- manifest: name "지금 거신 번호는", short_name "지금 거신 번호", display "standalone", orientation "portrait", theme_color와 background_color 지정
- 아이콘 192·512 PNG를 임시로 생성 (단색 배경 + 간단한 수화기 모양)
- index.html에 apple-touch-icon, apple-mobile-web-app-capable, apple-mobile-web-app-status-bar-style "black-translucent", apple-mobile-web-app-title 추가
- 서비스워커: registerType "autoUpdate", 빌드 결과물 사전 캐시

## 배포
- vite.config.ts의 base: '/<REPO_NAME>/'
- public/ 안의 에셋 경로는 import.meta.env.BASE_URL 기준으로 만든다
- .github/workflows/deploy.yml
  - 트리거: main 브랜치 push, 수동 실행(workflow_dispatch)
  - Node 20, npm ci, npm run build
  - actions/configure-pages → actions/upload-pages-artifact(dist) → actions/deploy-pages
  - permissions: contents read, pages write, id-token write
- 루트 README.md에 GitHub 설정 방법 한 줄: Settings → Pages → Source를 "GitHub Actions"로

## M2~M6 개요 (다음 문서 작성 후 확정)

**M2 — 메신저 엔진**: 대화방 목록과 1:1·단톡방 화면. inkjs로 `story/*.ink`를 불러와 태그(`# app`, `# from`, `# typing`, `# photo` 등)에 따라 말풍선, 입력 중 표시, 사진 메시지를 그린다. 선택지는 키보드 자리의 추천 답장 버튼. 여러 대화방을 동시에 진행하기 위한 이벤트 큐.

**M3 — 상태와 저장**: ink 변수와 게임 상태 동기화, 호감 단계에 따른 프사·상태 메시지·답장 지연 변화, 하루 결산 시 자동 저장, 날짜 선택 이어하기.

**M4 — 대면 장면·영상통화**: 폰 화면이 꺼지는 전환 → 1인칭 풀스크린 컷 + 하단 대사창. 전화 수신 화면(받기/거절), 영상통화 화면. 이미지 줌·흔들림 같은 미세 모션, 암전(`# fade`) 연출.

**M5 — 나머지 앱과 흐름도**: 사진첩(저장한 사진만), 캘린더(약속), 메모(독백, 김 사장님 수첩), 하루 결산 분기 흐름도.

**M6 — 콘텐츠 투입**: D1~D3 ink 스크립트와 이미지 교체, 실기기 플레이 테스트.
