# 07-1. 이미지 프롬프트 — D1까지 필요한 전부 (ChatGPT용)

지금 게임에서 비어 있는 이미지 22장 + 히로인 기준 얼굴 3장 = **총 25장**.
각 코드 블록을 그대로 복사해서 ChatGPT에 붙여넣으면 된다. 스타일과 금지 조건은 블록마다 이미 들어 있다.

---

## 0. 먼저 알아둘 것

**대화방을 나눈다.** ChatGPT는 같은 대화 안에서 인물을 더 잘 유지한다. 대화를 이렇게 나눠서 작업한다.

| 대화 | 만드는 것 |
|---|---|
| 대화 A — 서하 | 서하 기준 얼굴 → 서하 표정 3장 → 서하 장면 2장 |
| 대화 B — 이안 | 이안 기준 얼굴 (D2 대비) |
| 대화 C — 다온 | 다온 기준 얼굴 (D3 대비) |
| 대화 D — 사물·배경 | 배경 3장, 사물 사진 3장, 프로필 사진 11장 |

**기준 얼굴 고르기.** 기준 얼굴 프롬프트는 3~4번 다시 뽑아서 가장 마음에 드는 한 장을 고른다. 이게 그 인물의 얼굴이 된다. 이후 서하가 나오는 모든 프롬프트는 **그 이미지를 다시 첨부**해서 보낸다. 같은 대화 안이어도 첨부하는 게 얼굴이 덜 흔들린다.

**비율.** ChatGPT가 9:16을 정확히 못 맞추면 가장 긴 세로 비율로 뽑는다. 프롬프트마다 "중요한 건 가운데에"라는 조건을 넣어 두었으니, 나중에 좌우를 잘라 9:16으로 만들어도 괜찮다. 변환은 맨 아래 7장의 스크립트가 해 준다.

**파일 이름.** 받은 이미지는 아래 표의 파일명으로 저장한다(확장자는 PNG 그대로 둬도 된다. 변환 스크립트가 WebP로 바꾼다).

## 7. 변환 — Claude Code에 시킬 프롬프트

ChatGPT에서 받은 이미지는 크기와 비율이 제각각이다. 받은 파일을 전부 레포의 `raw/` 폴더에 위 파일명으로 넣고, Claude Code에 아래를 붙여넣는다.

```
raw/ 폴더의 이미지를 게임 규격으로 바꾸는 스크립트를 scripts/convert-images.mjs로 만들어 줘. sharp를 devDependency로 써도 돼.

규칙
- 파일명으로 종류와 폴더를 정한다 (docs/07_아트_파이프라인.md 규칙).
  - bg_로 시작 → public/assets/backgrounds/
  - _pfp_가 들어감 → public/assets/ui/
  - _ref_가 들어감 → public/assets/characters/
  - 그 외 → public/assets/cg/
- 크기
  - pfp: 가운데 기준 정사각형으로 자르고 512×512
  - 나머지: 가운데 기준으로 9:16으로 자르고 1080×1920
- 출력은 WebP 품질 80. 이미 같은 이름의 파일이 있으면 덮어쓴다.
- 입력 확장자는 png, jpg, jpeg, webp 모두 받는다.
- 끝나면 변환한 파일 목록과 각 파일이 들어간 폴더를 출력한다.
- raw/ 폴더는 .gitignore에 추가한다 (원본은 레포에 올리지 않음).
- package.json에 "images": "node scripts/convert-images.mjs" 추가.

만든 다음 npm run images를 한 번 실행해서 결과를 보고해 줘.
```
