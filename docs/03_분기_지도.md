# 03. 분기 지도 (초안)

> 상태: **초안 (엔진 쪽 뼈대)** — `01_기획서.md` 7·8장과 `02_캐릭터_바이블.md`를 대본 구조로 옮긴 것.
> 사건의 세부 내용, 수치 기준, 플래그 이름은 **대본을 쓰는 사람이 확정**한다. 확정되면 "초안" 표시를 지운다.

## 1. 하루의 구조

| 구간 | 시각 (`# time:`) | 대본에서 일어나는 것 | 쓰는 태그 |
|---|---|---|---|
| 아침 | 07:30~09:30 | 알림 확인, 밤사이 온 메시지 답장 | `# room` · 추천 답장 |
| 낮 | 11:00~17:00 | 약속 1개(수리 의뢰 또는 만남). 겹치면 하나만 | `# plan` → `# scene` |
| 저녁 | 18:00~21:00 | 약속 1개 또는 메시지 이벤트 | `# scene` / `# room` |
| 밤 | 21:00~ | 할 일 1개 선택 → (영상통화 이벤트) → 하루 결산 | 선택지 · `# call` · `# dayend` |

**밤의 할 일** (매일 같은 형태의 선택지)

```ink
* [유튜브로 수리 공부하기]
    ~ study()
    # note: 공부 기록
    오늘은 {~에스프레소 머신|형광등 안정기|수도꼭지 패킹} 영상을 세 개 봤다.
* [누군가에게 먼저 연락하기]
    -> night_contact
* [일찍 자기]
- # dayend
```

**수리 장면** — 의뢰마다 필요한 수리 실력이 있다. `skill`이 모자라면 두 선택지를 낸다.

```ink
{ skill >= 1:
    -> repair_success
- else:
    * [아는 척 도전하기] …      // 실패 연출(# fx: shake), 인물별 호감 변화
    * [솔직하게 못 한다고 하기] …  // 서하·다온은 정직을 높이 평가
}
```

## 2. 일자별 뼈대

| 일자 | 구간 | 사건 (기획서 7장) | 분기점 / 기록 |
|---|---|---|---|
| D1 월 | 공통 | 새 번호 개통, 초기 설정. 수리 의뢰 폭탄. 카페 에스프레소 머신 의뢰 — **윤서하 첫 만남**. 밤: 단골방 초대 | 서하 대면에서 아는 척/솔직 (`skill` 0이므로 반드시 둘 중 하나) |
| D2 화 | 공통 | 윗집 형광등 — **채이안 첫 만남**. 저녁: 김다온 첫 메시지 "그 번호 왜 쓰세요." | 다온에게 번호 사정을 솔직히 말하는지 |
| D3 수 | 공통 | 동물병원 앞 **김다온 대면**. 할아버지의 의뢰 수첩 받음 | 수첩 해금: 이날부터 `# page:` 사용 |
| D4 목 | 공통 | 서하·이안 의뢰가 **동시에** 옴 — 첫 양자택일. 단톡방 신경전. 밤: 첫 영상통화 | `# open:` 또는 의뢰 선택, `# call: … # video` |
| D5 금 | 공통 | 한강공원 봄밤 행사에서 셋과 동시 조우. **밤: 루트 결정** | 아래 3장 |
| D6~D13 | 개별 | 히로인 루트. D8 갈등, D10 김 사장님 전화, D11 위기, D12 고백 | 루트별 파일 |
| D14 일 | 엔딩 | 엔딩 분기 | 아래 4장 |

## 3. 루트 결정 (D5 밤) — 기준 초안

```ink
=== d05_route ===
{
- aff_seoha >= 40 && aff_seoha >= aff_ian && aff_seoha >= aff_daon && f_seoha_key: -> seoha_route
- aff_ian   >= 40 && aff_ian   >= aff_daon && f_ian_key:   -> ian_route
- aff_daon  >= 40 && f_daon_key:  -> daon_route
- else: -> alone_route      // "혼자인 2주" 짧은 루트
}
```

| 루트 | 기준치(초안) | 핵심 플래그 후보 (바이블의 "오름" 행동에서) |
|---|---|---|
| 서하 | 40 | `f_seoha_key`: D1 또는 D4에 솔직하게 말했다 |
| 이안 | 40 | `f_ian_key`: 새벽 연락(D4 영상통화)에 답했다 |
| 다온 | 40 | `f_daon_key`: 약속 시간을 지켰고 거짓말하지 않았다 |

- 동점이면 표의 위쪽이 우선한다(임시). 필요하면 D5 밤에 "누구에게 먼저 연락하기" 선택으로 정한다.
- 기준치 40은 D1~D5에 한 사람에게 집중하면 닿고, 셋에게 나누면 못 닿는 값으로 잡았다(`04_시스템_명세.md` 2장 가이드). 플레이 테스트로 조정한다.

## 4. 엔딩 조건 (D13 밤 판정) — 초안

| 엔딩 | 조건 |
|---|---|
| ○○ 굿 | 루트 진입 + 호감 75 이상(4단계) + 루트 플래그(D11 위기에서 도망치지 않음 등) |
| ○○ 노멀 | 루트 진입 + 굿 조건 불충족 |
| 번호 반납 | 어떤 루트에도 진입하지 못함 (`alone_route`) |

## 5. 대본 파일 구성

```
story/
  main.ink        진입점: INCLUDE 목록과 -> d01
  system.ink      변수·도우미 함수 (엔진이 읽음)
  d01.ink ~ d05.ink         공통 구간 (knot: d01_morning, d01_day, d01_evening, d01_night …)
  route_seoha.ink / route_ian.ink / route_daon.ink / route_alone.ink
  endings.ink
```

- 날마다 첫 줄에 `# day: N`을 붙인다(날짜 선택 저장 지점이 된다).
- 날마다 밤 끝에 `# dayend`를 **따로 한 줄로** 둔다(하루 결산 흐름도).
- `demo.ink`(엔진 시험용)는 D1 대본을 쓰면 main.ink의 INCLUDE에서 뺀다.
