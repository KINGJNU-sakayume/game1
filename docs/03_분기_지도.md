> 상태: **확정 (D1~D14 대본 기준)**. 수치는 `npm run playtest` 결과로 맞췄다(아래 7장).

## 1. 하루의 구조

| 구간 | 시각 (`# time:`) | 대본에서 일어나는 것 | 선택이 나오는 곳 |
|---|---|---|---|
| 아침 | 07:30~10:30 | 알림 확인, 밤사이 온 메시지 답장, 동네 소식 | 메신저 추천 답장, 스냅·망원살이 |
| 낮 | 11:00~17:00 | 약속 1개(수리 의뢰 또는 만남). 겹치면 하나만 | **지도** (`# go:`) → 대면 장면 |
| 저녁 | 18:00~21:30 | 약속 1개 또는 메시지·전화 이벤트 | 대면 장면, 전화 수신 |
| 밤 | 22:00~ | 할 일 1개 → (영상통화) → 하루 결산 | 행동 시트 → **튜브** (`# watch:`) / **전화** (`# text:` · `# dial:`) |

**밤의 할 일** (날마다 같은 모양. 영상 목록과 연락할 사람은 날마다 다르다)

```ink
= night
# time: 22:10 # at: home
# ask: 오늘 밤 뭐 하지?
* [튜브로 수리 공부하기 # act]
    # ask: 오늘 밤 볼 영상
    * * {not k_boiler} [보일러에서 쇠 긁는 소리가 날 때 # watch: boiler]
        -> video_boiler ->          // videos.ink의 터널: 재생 화면 → 핵심 정리 → k_boiler, skill +1
    * * [그만 보기]
    - - -> close
* [누군가에게 먼저 연락하기 # act]
    -> contact                      // 전화 앱에서 사람 고르기 (# text: / # dial:)
* [일찍 자기 # act]
    -> close
```

**수리 장면** — 의뢰마다 필요한 지식(`k_…`)이 있다. 영상을 봤거나 수첩의 그 쪽을 읽었으면(`read("…")`) "배운 대로 하기"가 열린다.

```ink
* {k_boiler || read("해든빌라 (보일러)")} [배운 대로 공기 빼기]
    …                                // 성공, 호감 +
* [아는 척 도전하기]
    # fx: shake                      // 실패 연출. 서하·다온은 싫어한다
* [솔직하게 못 한다고 하기]            // 서하·다온은 정직을 높이 평가
```

## 3. 루트 결정 (D5 밤, `d05.ink`의 `d05_route`)

```ink
// 자격: 호감 35 이상 + 핵심 플래그. 자격이 없으면 -1
// 동점이면 장터에서 끝까지 함께 있던 사람(d5_with)에게 +1
{
- s < 0 && i < 0 && d < 0: -> alone_d05_night
- s >= i && s >= d:         -> seoha_d05_night
- i >= d:                   -> ian_d05_night
- else:                     -> daon_d05_night
}
```

| 루트 | 기준치 | 핵심 플래그 | 얻는 곳 |
|---|---|---|---|
| 서하 | 35 | `f_seoha_key` 서하에게 솔직했다 | D1 수리 / D4 그라인더 |
| 이안 | 35 | `f_ian_key` 새벽 연락에 답했다 | D2 밤 낙서(또는 D3 아침) / D4 새벽 영상통화 |
| 다온 | 35 | `f_daon_key` 시간을 지켰고 거짓말하지 않았다 | D3 8시 / D5 4시 (거짓말하면 둘 다 소용없음) |

- 기준치 35는 D1~D5에 한 사람에게 집중하면 넉넉히 닿고(집중 플레이 평균 60 안팎), 무작위로 고르면 절반쯤 못 닿는 값이다.
- 누구에게도 자격이 없으면 **혼자인 2주**. 벌이 아니라 이 게임의 제목을 가진 짧은 루트다.

## 6. 대본 파일 구성

```
story/
  main.ink        진입점: INCLUDE 목록과 -> d01
  system.ink      변수·도우미 함수 (엔진이 읽음)
  videos.ink      튜브 영상 터널 (video_boiler 등). 수리 지식 k_…를 켠다
  boss.ink        김 사장님: 튜브 "제주 만물수선" 추천(jeju_offer), 전화 앞뒤(boss_call_open / boss_call_close)
  d01.ink ~ d05.ink         공통 구간
  route_seoha.ink / route_ian.ink / route_daon.ink / route_alone.ink
  endings.ink
```

- 날마다 첫 줄에 `# day: N`을 붙인다(날짜 선택 저장 지점이 된다).
- 날마다 밤 끝에 `# dayend`를 **따로 한 줄로** 둔다(하루 결산 흐름도).
- 루트 파일의 knot 이름은 `seoha_d06`처럼 `루트_d날짜`. 시뮬레이터가 이 이름으로 루트를 알아본다.

## 7. 밸런스 (npm run playtest, 300회씩)

| 플레이 방식 | 루트 | 엔딩 |
|---|---|---|
| 무작위 | 혼자 약 50~60%, 다온·이안·서하 순 | 굿 엔딩은 드물다 (합 5% 안팎) |
| 모두에게 친절 | 이안·서하·다온 고루 | 굿 엔딩이 대부분 |
| 서하 집중 | 서하 100% | 굿 약 55~70% (로스터와 재계약이 모두 필요) |
| 이안 집중 | 이안 약 97% | 굿 약 95% |
| 다온 집중 | 다온 100% | 굿 약 100% |

- 1회차 평균 대사 약 700줄, 선택 약 85번. 무작위 플레이도 막다른 길 없이 모두 엔딩에 닿는다.
- 서하 굿 엔딩이 가장 어렵다: D7에 로스터를 받아 오고, 영상 두 편(또는 사장님 조언)으로 `roaster_step` 2를 채우고, D11에 도망치지 않아야 한다. D11에 실패해도 D12 밤 공부 → D13 재도전으로 만회할 수 있다.
