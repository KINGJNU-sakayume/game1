# 05. 스크립트 문법 (초안)

> 상태: **초안** — M2 엔진 구현과 함께 작성. 사람이 대본을 쓰기 시작하면 필요에 맞게 고친다.
> M5 이후 태그는 해당 마일스톤에서 이 문서에 추가한다. 화면 연출의 모양과 시간은 `06_UI_연출_명세.md`.

대본은 [ink](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md) 언어로 쓴다. `story/main.ink`가 진입점이고, 날짜별 파일은 `INCLUDE`로 붙인다. 빌드할 때 컴파일되며, 문법 오류가 있으면 **빌드가 실패**하고 파일·줄 번호가 표시된다(GitHub Actions 로그에서도 보인다).

---

## 1. 기본 규칙

- 대사 한 줄 = 말풍선 하나. 한 말풍선은 1~2문장(기획서 10장).
- 줄 끝이나 **바로 윗줄**에 `# 태그`를 붙여 연출을 지정한다. 태그만 있는 줄은 **다음 대사 줄**에 붙는다.
- 태그는 `# 이름: 값` 또는 `# 이름` 형태. 한 줄에 여러 개를 붙일 수 있다: `# room: ian # typing: 2`
- 주인공 이름은 `{player_name}`으로 쓴다 (설정 앱에서 바꾸면 즉시 반영).
- 대사 안에 `#`을 글자로 쓰려면 `\#`로 쓴다.

```ink
=== d1_morning ===
# day: 1
# time: 08:10
# room: dangol # from: choi
김 사장님 번호 살아있네? 누구세요~
```

## 2. 태그 목록 (M2: 메신저)

### 대사 줄에 붙이는 태그

| 태그 | 값 | 유지 | 설명 |
|---|---|---|---|
| `# room:` | 방 id | **다음 줄에도 유지** | 이 줄부터 메시지가 올라갈 대화방 |
| `# from:` | 인물 id / `me` / `system` | 이 줄만 | 보낸 사람. 1:1 방에서는 생략하면 상대방. **단톡방에서는 필수** |
| `# typing:` | 초 (예: `2.5`) | 이 줄만 | 입력 중 표시 시간. 생략하면 글 길이로 자동(0.8~3초) |
| `# photo:` | 이미지 파일명 | 이 줄만 | 사진 메시지. 줄의 글은 사진 설명(대체 텍스트)으로 쓴다 |
| `# big` | — | 이 줄만 | 큰 글씨 스티커처럼 표시 (박 할머니용) |
| `# wait:` | 초 | 이 줄만 | 이 줄을 보여주기 전에 쉬는 시간 |
| `# time:` | `HH:MM` | 다음 태그까지 | 게임 시각 변경. 이후 메시지의 시각이 된다 |
| `# day:` | 숫자 (1=3월 9일 월) | 다음 태그까지 | 게임 날짜 변경 |

- 시간은 설정 앱의 **텍스트 속도**에 따라 늘거나 준다 (느림 1.6배, 보통 1배, 빠름 0.5배).
- `from: me`로 쓴 줄은 주인공이 먼저 보내는 메시지다 (선택지 없이).
- `from: system`은 "○○님이 초대되었습니다" 같은 가운데 안내문. 안 읽음 수에 들어가지 않는다.

### 선택지 태그 — 반드시 `[ ]` 안에 쓴다

선택지는 대화방 아래 **추천 답장** 버튼으로 나온다. 버튼 글은 항상 `[ ]` 안에 쓴다. 선택하면 그 글이 주인공 메시지로 전송된다.

```ink
* [네, 오늘 가능해요]
    잘됐다. 스팀 노즐이 안 나와서요.
```

| 태그 (`[ ]` 안) | 설명 |
|---|---|
| `# say: 보낼 말` | 버튼 글과 실제로 보내는 말을 다르게 할 때 |
| `# draft: 지울 말` | **썼다 지우기**: 입력창에 이 말을 쳤다가 지우고 선택한 말을 보낸다 |
| `# act` | 메시지를 보내지 않는 행동 (예: "나중에 답하기", "읽고 넘기기") |
| `# open: 방id` | **동시 도착**: 버튼 대신, 플레이어가 **먼저 연 방**이 선택된다 |

```ink
* [사실 저 사장님이 아니라서요 # draft: 네 물론이죠! 언제 갈까요?]
* [잘 모르는데… 솔직히 # say: 솔직히 잘은 모르는데, 한번 볼게요]
* [나중에 답하기 # act]
```

**동시 도착** — 모든 선택지에 `# open:`이 있으면 추천 답장이 뜨지 않고, 대화 목록에서 먼저 연 방이 선택된다. 선택지를 띄운 순간 플레이어가 이미 그 방 중 하나를 보고 있으면 그 방이 선택된다.

```ink
# room: ian
안녕하세요!! 윗집인데요
# room: daon
김용수 사장님 번호 쓰시는 분 맞죠.
* [ian # open: ian]
    -> ian_first
* [daon # open: daon]
    -> daon_first
```

> ⚠ `* [선택] # 태그`처럼 괄호 **밖**에 쓴 태그는 선택지가 아니라 그다음 줄에 붙는다.
> 괄호 없이 `* 네` 로 쓰면 ink가 선택한 글을 한 줄 더 출력하는데, 엔진이 이 줄을 자동으로 건너뛴다. 되도록 괄호를 쓴다.

## 2-1. 대면 장면 · 통화 태그 (M4)

`# scene:` 또는 `# call:`이 시작되면 그다음 대사는 메신저가 아니라 **화면 전체의 대사창/자막**에 나오고, 플레이어가 **탭해야** 넘어간다. `# scene: end` · `# call: end`로 끝내면 다시 메신저로 돌아간다.

| 태그 | 값 | 설명 |
|---|---|---|
| `# scene:` | 컷 이미지 이름 | 대면 장면 시작 (폰이 꺼지듯 어두워진 뒤 컷). `end`면 끝 |
| `# cut:` | 컷 이미지 이름 | 장면·영상통화 중 컷 바꾸기 (암전도 풀림) |
| `# fx:` | `zoom` / `shake` | 컷에 빠른 확대 / 흔들림 |
| `# fade` | — | 암전. 다음 대사는 검은 화면 위에 나온다 |
| `# call:` | 인물 id | 전화가 온다(수신 화면). `end`면 통화 끝 |
| `# video` | — | `# call:`과 함께: 영상통화 |
| `# outgoing` | — | `# call:`과 함께: 주인공이 건 전화 (받기/거절 없이 연결) |

**장면 안의 대사**
- `# from:`이 없으면 **서술**(1인칭 현재형, 괄호 독백). 인물이 말하면 `# from: seoha`, 주인공이 말하면 `# from: me`.
- 통화 중에는 `# from:`이 없으면 **통화 상대**의 말.
- 선택지는 그대로 `* [ ]`로 쓴다. `# say:`가 있으면 고른 뒤 주인공 대사로 한 번 보여준다.

```ink
# time: 14:00 # scene: bg_cafe_day_01
카페 오후세시. 문을 열자 커피 냄새가 먼저 온다.
# cut: seoha_scene_machine_01 # from: seoha
오셨어요? 이거예요, 스팀이 하나도 안 나와요.
* [아는 척 도전하기]
    # fx: shake
    푸슉— 뜨거운 김이 사방으로 튄다.
* [솔직하게 모른다고 하기 # say: 솔직히 이 모델은 처음 봐요.]
    ~ raise(aff_seoha, 10)
- # fade
그날 오후는 생각보다 길었다.
# scene: end
```

**받을까 말까** — 수신 화면의 받기/거절 버튼이 곧 선택지다. `# answer` · `# decline`을 `[ ]` 안에 붙인다.

```ink
# call: ian # video
* [받기 # answer]
    # cut: ian_call_night_01
    앗 받았다 ㅋㅋ 안 자고 있었죠?
    # call: end
* [거절 # decline]
    # room: ian
    앗 자는구나 🥲
```

- 거절하면 통화 화면이 바로 닫히고 전화 앱에 "거절한 통화"로 남는다. 그다음 대사는 메신저로 간다.
- 통화 기록(받은/건/거절, 통화 시간)은 전화 앱에 자동으로 쌓인다.

## 5. 흐름과 진행

- 대본은 설정을 마친 순간부터 흐른다. 잠금화면·홈 화면에 있어도 메시지는 도착하고, 알림 배너와 배지로 알려 준다.
- **선택지가 나오면 대본이 멈추고** 플레이어가 답할 때까지 기다린다. 답장을 기다리는 방은 대화 목록에 주황 점으로 표시된다.
- 대본이 `-> END`에 닿으면 멈춘다.
- 선택지가 나올 때마다 자동 저장되어, 앱을 다시 열면 그 선택지부터 이어진다. `# day:`로 날짜가 바뀌면 날짜별 시작 지점도 저장된다(설정 앱 → 날짜 선택). 자세한 내용은 `04_시스템_명세.md`.

## 5-1. 변수와 호감 (M3)

변수는 `story/system.ink`에 있다. 자세한 규칙은 `04_시스템_명세.md`.

```ink
* [사실 잘 모르는데요]
    ~ raise(aff_seoha, 10)     // 호감 +10
    솔직해서 좋네요 :)
{aff_seoha >= 25: 어제 감사했어요 :)|안녕하세요.}   // 호감에 따라 다른 대사
```

- 1:1 방에서 주인공이 보낸 메시지 옆 **"1"** 은 상대가 읽으면 사라진다. 읽는 시간은 호감 단계와 인물마다 다르다. 특정 장면에서 일부러 늦게 읽게 하려면 상대 대사에 `# wait: 초`를 붙인다.

## 6. 대본 작성 체크리스트

- [ ] 단톡방 줄에 `# from:`을 빠뜨리지 않았다
- [ ] 선택지 태그를 `[ ]` 안에 썼다
- [ ] `# scene:` · `# call:`을 `end`로 닫았다 (거절 갈래 제외)
- [ ] `# time:`이 앞 시각보다 거꾸로 가지 않는다
- [ ] 사진 파일명이 07 문서의 규칙을 따른다
- [ ] `npm run build`가 통과한다
