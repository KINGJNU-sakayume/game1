# 07. 아트 파이프라인 & 이미지 프롬프트

## 1. 규격

| 종류 | 크기 | 포맷 |
|---|---|---|
| 대면 컷·영상통화·셀카·배경 | 1080×1920 (9:16 세로) | WebP, 품질 80 |
| 표정 스프라이트 (기준 이미지 파생) | 1080×1920 | WebP |
| 프로필 사진 | 512×512 | WebP |
| 앱 아이콘 | SVG 또는 512×512 PNG | — |

## 2. 파일명 규칙

`{인물}_{종류}_{세부}_{번호}.webp` — 영문 소문자와 밑줄만 사용.

- 인물: `seoha`, `ian`, `daon`, `mc`(주인공 손), `bg`(배경), `dubu`(두부 — 스냅 계정 사진), `tube`(튜브 영상 화면)
- 종류: `ref`(기준), `face`(표정), `selfie`, `scene`(대면 컷), `call`(영상통화), `pfp`(프로필), `cg`(이벤트)
- 예: `seoha_face_smile_01.webp`, `ian_pfp_stage2_01.webp`, `bg_cafe_night_01.webp`

스크립트의 태그는 확장자 없이 파일명을 그대로 쓴다: `# photo: ian_selfie_desk_01`

## 3. 제작 순서

1. **기준 이미지 확정** — 히로인마다 아래 REF 프롬프트로 여러 장 뽑아 1장을 고른다. 이게 그 인물의 "얼굴"이다.
2. **표정 세트** — 기준 이미지를 레퍼런스로 첨부해 표정 5종을 파생한다.
3. **프로필 사진·셀카** — 호감 단계별 프사, 초반 셀카.
4. **대면 컷** — 스토리를 쓰면서 필요한 장면만 그때그때.
5. **배경** — 폰 배경화면, 대면 장면 배경.

레퍼런스 이미지 입력을 지원하는 생성 도구를 쓴다(예: ChatGPT 이미지 생성, Gemini 이미지, Midjourney 레퍼런스 기능 등). 파생 이미지는 **항상 기준 이미지를 첨부**하고, 문장에 "same person as the reference"를 넣는다.

## 4. 일관성 규칙

- 인물마다 **고정 요소 1개**를 모든 이미지에 넣는다: 서하 = 왼손목 은팔찌, 이안 = 목에 건 흰 헤드폰, 다온 = 왼쪽 눈 아래 작은 점.
- 같은 날의 컷은 같은 의상. 의상이 바뀌는 날은 `02_캐릭터_바이블.md` 기준으로.
- 실존 인물(연예인 포함)을 닮지 않은 오리지널 얼굴로 만든다.
- 주인공 얼굴은 절대 나오지 않는다. 필요하면 손과 소매만.

## 5. 공통 블록 (모든 프롬프트 끝에 붙임)

**스타일 블록**
```
candid smartphone photo, shot on a recent iPhone, natural available light, subtle film grain, slightly imperfect framing, realistic skin texture, shallow depth of field, vertical 9:16, Seoul, spring
```

**1인칭 시점 블록** (대면 컷·영상통화용)
```
first-person point of view, camera at the viewer's eye level as if the viewer is standing in front of her, she is looking directly into the lens
```

**금지 블록** (모든 이미지)
```
no text, no captions, no watermark, no logos, no extra fingers, no distorted hands
```

**인물 블록** (히로인이 나오는 이미지에 추가)
```
adult woman, original face not resembling any real person or celebrity, fully clothed
```

## 9. 대본이 부르는 이미지 목록 (남은 그림)

대본(`story/*.ink`)의 `# scene:` · `# cut:` · `# photo:` · `# gallery:`가 부르는 이미지 가운데 **아직 파일이 없는 것**. 파일이 없어도 게임은 자리표시로 돌아가므로, 위에서부터(날짜 순) 그리면 된다. "장면"은 그 이미지가 처음 나오는 줄의 대본이다 — 프롬프트는 6~8장의 틀에 이 장면을 넣어 만든다.

- 사진 메시지·게시물(`# photo:`)은 히로인이 **직접 찍어 보낸** 사진이다. 셀카가 아니면 인물 없이 물건·장소만(얼굴 없는 손 정도).
- `dubu_…`는 병원 식구들이 두부(치즈 고양이)를 찍은 스냅 사진. 스타일 블록 + 금지 블록, 인물 없음.
- `tube_cg_jeju_hands_01`은 튜브 영상 화면: 늙은 손 두 개가 낡은 트랜지스터라디오를 쥐고 있다. 얼굴 없음, 16:9로 잘려 보이므로 가운데에 손을 둔다.

대본이 부르는 이미지 99장 중 **84장이 아직 없다** (2026-09 기준, `public/assets/`와 비교).
