# 06. UI·연출 명세

> 상태: **확정** — M1~M5와 새 앱(튜브·지도·스냅·망원살이) 구현 결과. 실기기 플레이 후 수치를 조정한다.
> 대본에서 쓰는 태그는 `05_스크립트_문법.md`, 수치 규칙은 `04_시스템_명세.md`.

## 1. 화면 층

아래에서 위로 쌓인다. 위층이 아래층을 덮는다.

| 층 | 내용 | 언제 |
|---|---|---|
| 1 | 초기 설정 / 잠금화면 / 홈 화면 | 항상 |
| 2 | 앱 화면 (앱 10개) | 아이콘을 누르면 아이콘 위치에서 확대되며 열림 (220ms) |
| 2-1 | **알약** (진행 알림) | 이야기가 **다른 앱**에서 선택을 기다릴 때. 홈 화면에서는 시계 아래 카드, 앱 안에서는 헤더 바로 아래(본문을 밀어 내며 내려옴 — 아무것도 가리지 않는다) |
| 3 | 알림 배너 | 다른 방·다른 앱에 소식이 오면 3.5초. 누르면 그 방·앱으로, **위로 밀면 숨김**(끄는 동안은 손가락을 따라가고 저절로 사라지지 않음) |
| 4 | **무대**: 대면 장면 · 통화 · 영상 재생 | 대본의 `# scene:` · `# call:` · `# play:` |
| 4-1 | 행동 선택 시트 | 모든 선택지가 `# act`일 때 (밤의 할 일 등). 어두운 배경 위로 아래에서 올라옴 |
| 5 | 하루 결산 흐름도 | 대본의 `# dayend` |
| 6 | 엔딩 카드 | 대본의 `# ending:` |

- 상단 safe-area(노치·다이내믹 아일랜드)에는 어떤 UI도 두지 않는다. 가짜 상태바는 만들지 않는다.
- 화면 바깥 가장자리 색(iOS가 칠하는 부분)은 현재 화면의 하단 색을 따른다.

## 2. 메신저

- 대화 목록: 최신 메시지 순. 안 읽음 수(빨간 배지), 답장을 기다리는 방(주황 점 — 안 읽은 배지가 있으면 줄 전체를 옅은 강조색과 왼쪽 선으로 표시).
- 동시 도착(`# open:`)이면 목록 위에 "누구의 메시지를 먼저 볼까요? 먼저 연 대화방이 선택이 됩니다." 안내가 나오고, 후보 방들이 강조된다.
- 대화방: 같은 사람이 연달아 보낸 말풍선은 묶고, 묶음의 첫 말풍선에만 아바타·이름(단톡방), 마지막에만 시각을 붙인다. 날짜가 바뀌면 가운데 날짜 구분선.
- 입력 중 표시: 점 세 개가 튀는 말풍선.
- 추천 답장: 키보드 자리에 선택지 버튼. 누르면 입력창에 글자가 쳐진 뒤 전송된다(썼다 지우기면 쳤다가 지운 뒤 다시). `# attach:` 답장은 사진이 전송된다.
- 읽음: 1:1 방에서 주인공 말풍선 옆 "1"이 상대가 읽으면 사라진다.
- 프로필: 아바타를 누르면 큰 프로필 사진 + 상태 메시지. 1:1 방 헤더 이름 아래에도 상태 메시지.

## 3. 대면 장면

"약속 시간이 되면 폰 화면이 꺼지듯 어두워지고, 1인칭 풀스크린 실사 컷 + 하단 대사창" (기획서 4장)

| 단계 | 연출 | 시간 |
|---|---|---|
| 시작 | 화면 전체가 검게 덮인 뒤(폰이 꺼지는 느낌) 컷이 서서히 나타난다 | 약 1초 |
| 진행 | 풀스크린 컷(9:16, 화면을 꽉 채움) + 하단 대사창. 탭하면 다음 대사 | — |
| 컷 전환 | `# cut:` 새 컷이 0.6초 동안 페이드인 | 0.6초 |
| 미세 모션 | 모든 컷은 16초에 걸쳐 5% 천천히 확대(살아 있는 느낌). `# fx: zoom` 빠른 확대(0.9초, 14%), `# fx: shake` 흔들림(0.45초) | |
| 암전 | `# fade` 화면이 1.1초에 걸쳐 검게. 다음 `# cut:`이 나오면 풀린다. 친밀한 장면은 암전 뒤 다음 날 아침 메시지로 넘긴다(기획서 10장) | 1.2초 |
| 끝 | `# scene: end` 무대가 0.6초 동안 사라지며 원래 폰 화면이 다시 보인다 | 0.6초 |

**대사창**
- 이름표: 말하는 사람 이름(강조색). 주인공은 플레이어 이름.
- 이름 없는 줄은 **서술**(1인칭 현재형, 괄호 독백 포함). 흐린 흰색으로 구분한다.
- 글자가 한 자씩 나타난다(느림 18 / 보통 32 / 빠름 70자/초). 치는 중에 탭하면 끝까지 바로 보이고, 다 나온 뒤 탭하면 다음 줄. 다 나오면 ▼ 표시.
- 선택지: 대사가 다 나온 뒤 대사창 위에 흰 버튼으로. 고른 말은 `# say:`가 있을 때만 주인공 대사로 한 번 더 보여준다.

## 4. 통화

| 화면 | 내용 |
|---|---|
| 수신 | 상대 아바타(흔들림), 이름, "음성통화/영상통화", 아래에 **거절(빨강)** · **받기(초록)**. 이 두 버튼이 곧 선택지 |
| 발신 (`# outgoing`) | "연결 중…" 1.8초 뒤 자동 연결 |
| 음성통화 | 어두운 그라데이션, 큰 아바타, 이름, 통화 시간(실제 초), 가운데 정렬 자막, 장식용 버튼(음소거·종료·스피커) |
| 영상통화 (FMV) | 상대 컷이 화면을 꽉 채움(`# cut:`), 오른쪽 위 내 화면(작은 사각형), 이름·통화 시간, 자막 |
| 끝 | `# call: end` 또는 거절 → 무대가 사라지고 전화 앱의 최근 통화에 기록 |

| 모르는 번호 (`# unknown`) | 아바타 대신 사람 실루엣, 이름 대신 번호, "저장되지 않은 번호 · 음성통화". 자막 이름표는 말하는 사람이 밝힌 이름 |
| 연결 안 됨 (`# noanswer`) | "연결 중…"이 이어지다 끝난다. 기록에 "연결 안 됨" |

- 통화 종료 버튼은 장식이다(대본이 통화를 끝낸다). 플레이어가 끊는 기능이 필요하면 선택지로 만든다.

**전화 앱** — 탭 세 개.

| 탭 | 내용 |
|---|---|
| 최근 기록 | 받은/건/거절/부재중/연결 안 됨, 영상 여부, 통화 시간, 날짜·시각. 거절·부재중은 빨간 이름. 모르는 번호는 번호로 |
| 연락처 | 메시지·전화·음성 메시지가 오간 사람(번호가 있는 사람만). 사람을 누르면 번호, 한 줄 소개, **알게 된 것**(`# memo:`), 메시지·전화·영상통화 버튼. 대본이 연락할 사람을 고르게 할 때(`# text:` · `# dial:`) 그 버튼이 선택지가 된다 |
| 음성사서함 | 음성 메시지 목록. 누르면 펼쳐져 받아쓰기 내용이 보이고 "들음"이 된다 (안 들은 것은 배지 숫자). 모르는 번호의 메시지는 번호로 |

## 5. 나머지 앱

| 앱 | 화면 |
|---|---|
| 사진 | 탭: 모든 사진 / 받은 사진 / 내가 찍은 사진. 날짜별 3열 격자(최근 날짜 위). 누르면 크게 보기(보낸 사람·날짜 설명). **저장한 사진과 주인공이 찍은 사진만** 남는다 |
| 캘린더 | 3월 달력(게임 기간만 누를 수 있음), 오늘은 빨간 원, 약속 있는 날은 점. 고른 날의 날씨, 행사(`# event:`), 약속 목록. 같은 시각에 겹친 약속은 "겹침", 포기한 약속은 줄이 그어진 채 "취소" |
| 메모 | 탭: 메모 / 할 일 / 사장님 수첩(D3부터). 수첩은 누런 종이 색, **안 읽은 쪽에 빨간 점**(열어 보면 사라지고 대본의 `read()`가 참이 된다) |
| 설정 | 휴대폰 정보(이름, 전화번호, 개통일, 이 번호의 전 사용자), 텍스트 속도, 이름, 날짜 선택, **엔딩 기록**(본 엔딩 제목, 안 본 엔딩은 ??? + 누구의 엔딩인지), 데이터 초기화. 혼자인 2주에서는 번호 명의 이전 카드가 나온다 |

받은 사진을 크게 볼 때 아래에 **사진첩에 저장** 버튼(저장하면 "사진첩에 저장됨").

### 튜브 (어두운 앱)

- 시스템 설정과 상관없이 어두운 화면(`tone: dark`). 탭: **추천** / **보관함(본 영상 수)**.
- 추천: 이야기가 영상을 고르게 하면 맨 위에 "오늘 밤 볼 영상"(`# ask:` 제목) 칸이 강조되어 영상 카드가 나온다. 누르면 재생. 앱 태그가 없는 선택지("그만 보기")는 칸 아래 버튼. 고를 것이 없으면 안내 문구와 "다시 보기".
- 섬네일: 이미지가 없으면 영상의 색(`tint`) 위에 제목을 크게 쓴 섬네일을 만든다. 길이 배지.
- 보관함: 본 영상과 본 시각. 누르면 영상 정보와 **핵심 정리**(수리 전에 다시 보는 요점).

### 영상 재생 (무대, `# play:`)

| 부분 | 내용 |
|---|---|
| 플레이어 | 화면 위 16:9. 섬네일(또는 컷), "▶ 재생 중" 표시, 아래 가장자리에 빨간 재생 막대 — 실제 길이가 아니라 대사가 흐르는 동안 45초에 걸쳐 천천히 찬다 |
| 정보 | 제목, 조회수·올린 때, 채널 줄(동그란 채널 아이콘, 채널 이름, 길이) |
| 자막 | 화면 아래 자막 상자. 이름표는 채널 진행자(`host`), `# narr` 줄은 주인공 속생각 |
| 끝 | `# play: end` → 무대가 사라지고, 핵심 정리가 보관함과 메모("공부 기록")에 남는다 |

### 지도

- 망원동 그림 지도(SVG, 360×440): 월드컵로·포은로·강변북로·망원로, 망원시장 골목, 한강.
- 핀: 드러난 장소만(`# pin:` · `# at:` · `# go:`). 지금 있는 곳은 파란 원.
- 이야기가 갈 곳을 고르게 하면(`# go:`) 그 장소 핀이 빨갛게 **깜빡이고**, 아래 시트에 "오늘 낮, 어디부터 갈까?"(`# ask:` 제목)와 장소 목록이 나온다. 핀을 눌러도 고를 수 있다.
- 평소 시트: "지금 여기: ○○". 핀을 누르면 그곳에 다녀온 기록(날짜·시각·메모).

### 스냅 (SNS)

- 위에 계정 줄(전체 / 카페 오후세시 / 이안 그림일기 / 망원24 두부 …) — 누르면 그 계정 글만.
- 피드: 계정, 사진(정사각형), 좋아요·댓글 아이콘, 좋아요 수(게시물마다 정해진 수 + 내 좋아요), 본문, 댓글.
- 이야기가 반응을 고르게 하면(`# like:` · `# comment:`) 그 게시물이 "○○ 게시물" 제목과 함께 강조되고, 아래에 선택 버튼.
- 지운 게시물(`# unpost:`)은 피드에서 사라진다. 안 본 게시물 수가 배지.

### 망원살이 (동네 게시판)

- 머리: "망원동 · 이웃 N명이 보고 있어요".
- 목록: 분류 칩(동네생활·공지·나눔·부탁해요·모집·구인), 제목, 글쓴이 · 날짜, 댓글 수. 안 본 글 수가 배지.
- 이야기가 답글을 고르게 하면(`# town:` 선택지) 그 글이 강조되고, 글 안에서 답글 버튼을 고른다. 내 답글은 플레이어 이름으로 남는다.

### 홈 화면과 잠금화면

- 홈: 시계·날씨 위젯(망원동 날씨), 알약 카드, 앱 격자(사진·캘린더·메모·스냅·망원살이·설정), **독**(메신저·전화·튜브·지도).
- 아이콘: 새 소식은 빨간 숫자 배지, 고를 것이 있는 앱은 작은 점.
- 잠금화면: 날짜·시각, "고를 것이 있음" 카드(알약과 같은 내용), 대화방별 새 메시지, 부재중·음성 메시지, 스냅·망원살이 새 소식 카드. 카드를 누르면 잠금이 풀리며 그곳이 열린다.

## 6. 하루 결산 흐름도

"밤에 폰을 내려놓으면 그날의 분기 흐름도" (기획서 5장, 디트로이트 비컴 휴먼식)

- 어두운 전체 화면. 위에 "하루 결산"과 날짜.
- 세로 흐름선에 그날의 선택 지점이 시간순으로 이어진다: `시각 + 장소(방 이름 / 대면 / ○○ 전화 / 먼저 연 대화방)`.
- 각 지점의 갈래: **고른 선택**(강조색 채움), **다른 회차에 고른 선택**(흐린 채움), **잠긴 선택**(점선 + 자물쇠 + ???).
- 아래 "다음 날로" 버튼을 누르면 다음 날이 시작된다(그 시작 지점이 자동 저장된다).

## 6-1. 엔딩 카드

- `# ending:` 줄에서 뜬다. 어두운 전체 화면, 가운데 "ENDING", 누구의 엔딩인지(굿/노멀/번호 반납), **제목**, "지금까지 본 엔딩 N / 7".
- 아래에 "설정 앱의 날짜 선택으로 그날부터 다시 걸어 볼 수 있습니다." + 닫기 버튼. 닫으면 폰 화면으로 돌아간다.
- 본 엔딩은 설정 앱 "엔딩 기록"에 남는다.

## 7. 이미지가 없을 때

모든 이미지는 파일이 없으면 **파일명이 적힌 자리표시**로 대신한다(메신저: 회색, 무대: 어두운 그라데이션). 게임은 멈추지 않는다. 폴더 규칙:

| 이름 | 폴더 |
|---|---|
| `bg_`로 시작 | `public/assets/backgrounds/` |
| 그 외 컷·사진 | `public/assets/cg/` |
| 프로필 사진 | `public/assets/ui/` |

## 8. 동작 줄이기

iOS "동작 줄이기"가 켜져 있으면: 앱 열기·닫기는 페이드만, 컷 확대·흔들림·수신 흔들림 없음, 알약·지도 핀 깜빡임 없음, 대사는 한 번에 표시.
